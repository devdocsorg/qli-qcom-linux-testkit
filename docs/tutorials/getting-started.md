# Getting started with qcom-linux-testkit

This tutorial was generated by the Hosted Docs DocsGen pipeline from the public fork of Qualcomm Linux `qcom-linux-testkit`.

## What this repo is

`qcom-linux-testkit` collects test helpers and scripts used against Qualcomm Linux images. The fork used here is `devdocsorg/qli-qcom-linux-testkit`.

## Typical workflow

1. Clone the testkit next to your image build.
2. Point the runner at the device or QEMU target.
3. Execute the suite that matches the board you flashed.
